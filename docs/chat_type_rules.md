# 聊天类型判定规则

## 规则来源
通过分析微信DB实际数据（message_0.db），Msg_表名hash和Name2Id的rowid**没有直接映射关系**。
Name2Id表存储的是 `rowid → wxid/chatroom` 映射，但Msg_表名里的hash（如`1a2b3c4d...`）
不是Name2Id的rowid，无法直接通过hash找到对应的聊天。

## 判定规则

### 1. 群聊
- **条件**: message_content 中带 `wxid_xxx:` 前缀（如 `wxid_demo2:\n大家好`）
- **回复**: 需 @发言者名称，通过wxid查联系人DB找到显示名
- **会话名**: 从群成员wxid的contact.db中找群名（@chatroom的remark/nick）

### 2. 私聊
- **条件**: message_content 不带 wxid_xxx 前缀 + 总消息数 ≥ 20 + 有且仅有 2 个不同的 real_sender_id
- **回复**: 无需 @
- **会话名**: 对方wxid通过 uname2display 映射（remark > nick > wxid）

### 3. 自聊（对自己发消息/文件传输助手）
- **条件**: 总消息数 ≥ 20 + 有且仅有 1 个 real_sender_id
- **回复**: 无需回复

### 4. 未知
- **条件**: 总消息数 < 20
- **回复**: 无需回复

## 数据结构参考

### Name2Id 表
| rowid | name (wxid/chatroom) |
|-------|---------------------|
| 1     | 12345678901@chatroom |
| 2     | wxid_demo_self  (自己) |
| 3     | wxid_demo1  |

### Msg_xxx 表关键字段
| 字段 | 说明 |
|------|------|
| real_sender_id | Name2Id的rowid，标识发送者 |
| message_content | 群聊格式: `wxid_xxx:\n内容`; 私聊格式: 纯文本 |
| origin_source | 1=自己发送, 2=收到文本, 3=富媒体(图/文件/链接) |
| create_time | Unix时间戳 |

## 日志显示格式

```
[群聊][示例群聊][1a2b...3c4d] 📨 7条待回复
  💬 示例用户(wxid_demo1): example.com
  💬 小明(wxid_demo2): 大家好
[私聊][示例用户][5f6e...7d8c] 📨 3条待回复
  💬 示例用户(wxid_demo1): 好的
```

格式: `[类型][会话名][hash缩写]` + 每条消息: `💬 显示名(wxid): 内容`

## 回复判定规则

### 已回复检测（启动时）

#### 群聊已回复
- **条件**: 被判定为群聊，且该表最新一条消息的 content **不带** `wxid_xxx:` 前缀（即自己发的消息，origin_source=1）
- **效果**: 该群标记为已回复，不触发回复
- **逻辑**: 群聊中自己发的消息没有wxid前缀，最后一条是自己发的 = 已经回复过了

#### 私聊已回复
- **条件**: 被判定为私聊，且最新一条消息的 `real_sender_id` 对应自己的wxid
- **效果**: 该私聊标记为已回复，不触发回复

#### 启动判定
- 所有会话都已回复 → 不发送任何消息，进入等待新消息模式
- 有未回复的私聊 → 立即回复
- 有未回复的群聊 → 检查最近20条消息是否@了自己

### 群聊回复策略

#### 1. @触发（立即回复）
- 最近20条消息中有 `@自己wxid` → 立即回复
- 没有@ → 不回复该群

#### 2. 后续跟进（LLM判断）
- @自己后立即回复完毕 → 进入监控模式
- 之后每累积 **3条新消息** → 发给LLM
- LLM上下文: 最近 **20条消息**（含自己发的）
- LLM判断: 新消息是否与自己发的消息**有关系**
  - **有关系** → 回复
  - **无关系** → 跳过，继续等待

### 私聊回复策略
- 未回复（对方最后发言） → 立即回复，无需@

### 汇总流程

```
启动 → 遍历所有Msg表
  ├─ 判定类型(group/private/self/unknown)
  ├─ 检查是否已回复(最后一条消息)
  │   ├─ 群聊: 最新content无wxid前缀 = 已回复
  │   └─ 私聊: 最新sender是自己 = 已回复
  ├─ 未回复的私聊 → 立即回复
  └─ 未回复的群聊 → 检查最近20条@自己
      ├─ 有@ → 立即回复 → 监控模式(每3条→LLM判断)
      └─ 无@ → 跳过
```
